## 一、项目背景与定位

- 所有者：朱锦琰（重庆大学 机械设计制造及其自动化 2024 级）。
- 动机：单片机点灯、联网之后，下一级台阶是"电机 + 传感器 + 控制算法"的整车系统——循迹小车是嵌入式最经典的入门整车项目（也是电子竞赛常客）。PID 转向控制是它区别于"玩具车"的灵魂，而我专业课里的自动控制原理正好在这里落地。
- **⚠️ 作品集定位声明：本项目是用于个人主页 https://zzz1280.github.io 「项目实践」区展示的嵌入式系统作品**，与 11 号机械臂一静一动；跑黑线的演示视频是主页最"活"的素材，也可作为电赛 / 工创赛的技术储备。

## 三、技术路线（分阶段）

**技术选型**：ESP32 DevKitC（复用 08 经验，Arduino 框架）/ TB6612FNG 电机驱动（优于 L298N，压降小）/ 5 路灰度传感器（TCRT5000 模块）/ HC-SR04 超声波 / 18650 电池 ×2 + 降压模块 / HC-05 或 ESP32 自带蓝牙。
> BOM 预算约 80~120 元。底盘买现成亚克力套件，把时间花在控制算法而不是拧螺丝上。

- **阶段 0｜采购与总装（2~3 天）**：Agent 给 BOM 与接线总表 → 我组装底盘与电路 → **接线照片发 Agent 核对后才允许上电**。产出：能手动遥控前后左右的车。
- **阶段 1｜电机驱动（2~3 天）**：TB6612 驱动 + PWM 调速 + 差速运动学封装（`setVelocity(left, right)`）。产出：基本运动模块 + 简单遥控 demo。
- **阶段 2｜循迹（4~5 天）**：5 路传感器读线 → 加权偏差计算 → 先 P 控制跑通直道弯道 → 再加 D 抑制震荡，**记录每组 Kp/Kd 的表现**。产出：稳定跑完闭合黑线轨道（自己用电工胶布贴一条）。
- **阶段 3｜避障（2~3 天）**：HC-SR04 测距（注意温度补偿可略）→ 分级策略（减速 → 停 → 后退绕行）；避障与循迹的模式切换逻辑。
- **阶段 4｜参数在线调节（2 天）**：串口 / 蓝牙协议（如 `PID 0.8 0 1.2\n`）→ 运行时更新参数并掉电不丢失（存 NVS）。产出：不用重烧录就能调车。
- **阶段 5｜收尾（2~3 天）**：PID 调参记录整理、演示视频拍摄、README、主页卡片更新。

## 四、Agent 运行规范（精简版，务必遵守）

1. 角色：嵌入式系统工程师兼导师；重点教我 PID 调参的直觉（先 P 后 D 再 I、震荡了怎么办、曲线怎么读）和整车模块化架构。
2. 节奏：一次一个阶段，阶段结束汇报并等我确认；**每次改接线后都要照片核对再上电**。
3. 诚实红线：演示视频必须真实拍摄；PID 调参记录必须是真实实验数据，不许抄网上的参数冒充自己的实验。
4. **实物边界**：组装、接线、贴线轨、拍摄由我完成；Agent 负责 BOM、接线表、代码、调参方法与故障排查树（车画龙 / 冲出弯道 / 电机异响等）。
5. 范围控制：v1 不上编码器（开环 PWM 够用）、不做摄像头视觉循迹、不上 ROS；先把 PID 循迹调稳。
6. **安全红线**：电池接线防反接（串联二极管或防反接座）；电机电源与逻辑电源分开，共地；任何冒烟发烫立即断电。
7. 代码规范：按 motor / sensor / control / comm 分模块；控制环用定时器固定频率（如 100Hz），不用 delay 堆时序；关键逻辑中文注释。
8. 文档同步：每阶段更新「进度日志」。
9. 沟通：车行为异常时，按"现象 → 可能原因 → 最小验证实验"三段式向 Agent 描述，别只说"跑歪了"。

## 五、风险与注意

- 循迹翻车 top1 是传感器高度和间距：离地 5~10mm 起试，轨道用哑光电工胶布（反光胶布会干扰灰度）。
- 电池电压下降会导致 PWM 行为漂移：同组参数在满电和亏电下表现不同，调参记录要记电压。
- 灰度传感器受环境光影响：尽量在稳定光照下调参，决赛级问题阶段 5 再管。
