## 一、项目背景与定位

- 所有者：朱锦琰（重庆大学 机械设计制造及其自动化 2024 级）。
- 动机：入门嵌入式最怕"只看教程不动手"。做一块名片 PCB，能以最低成本（几十元）走完"原理图 → PCB 布局 → 打样 → 焊接 → 烧录点灯"的完整硬件流程，成品还能真的当名片用。
- **⚠️ 作品集定位声明：本项目是用于个人主页 https://zzz1280.github.io 「项目实践」区的硬件开篇作品**。实物照片在学生软件作品堆里极其稀缺——主页卡片放一张点亮的名片照片，说服力是纯软件项目的十倍。

## 三、技术路线（分阶段）

**技术选型**：立创 EDA（标准版，与嘉立创打样 / 立创商城无缝衔接；会 KiCad 也可）/ 单片机 CH32V003（约 1 元，RISC-V，WCH 官方工具链 MounRiver）或 STC8H（Keil 生态）；若想省事可焊 ESP32-C3 SuperMini 成品模组（~8 元，Arduino 生态）。
> 选型由 Agent 在阶段 0 给出对比表，与我确认后锁定。预算红线：整卡物料 ≤ 50 元。

- **阶段 0｜选型与学习（2~3 天）**：Agent 输出单片机选型对比表 → 我确认；过一遍"最小系统"概念（供电 / 晶振 / 复位 / 去耦电容）。产出：选型结论 + 原理图草图画法清单。
- **阶段 1｜原理图（2~3 天）**：立创 EDA 画原理图（Agent 远程逐步指导：元件搜索、网络标号、ERC 检查）。产出：通过 ERC 的原理图。
- **阶段 2｜PCB 布局布线（3~4 天）**：板框 → 元件摆放（LED 按名字排布）→ 布线（线宽 / 间距规范）→ 丝印名字与二维码 → DRC 检查 → 3D 预览确认颜值。产出：通过 DRC 的 PCB。
- **阶段 3｜打样与采购（1 天 + 等待 3~5 天）**：导出 Gerber 下单嘉立创；BOM 表 → 立创商城下单；同时 Agent 给焊接准备清单（烙铁温度、焊锡丝、顺序：先矮后高）。
- **阶段 4｜焊接与烧录（2~3 天）**：照 BOM 焊接（Agent 提供排障：不亮怎么查——电压表逐点测量流程图）；搭固件环境，烧录流水灯。
- **阶段 5｜收尾（1~2 天）**：拍"证件照"，写 README 踩坑记录，主页卡片更新。

## 四、Agent 运行规范（精简版，务必遵守）

1. 角色：硬件工程师兼导师；重点教我"电子设计与机械设计的相通性"（都是布局、公差和工艺）。
2. 节奏：一次一个阶段，阶段结束汇报并等我确认；**下单打样前必须把 Gerber / 3D 预览给我最终确认**，避免浪费打样额度。
3. 诚实红线：不替我虚构"已焊接成功"；我的实物照片是唯一验收依据。固件代码必须给我可编译的完整工程与烧录步骤。
4. **实物边界**：画板操作、焊接、拍照由我完成；Agent 只给逐步指导、检查截图、排障流程。
5. 范围控制：v1 不做贴片（全直插或大封装 0805 以上），不用双层以上复杂工艺；预算 ≤50 元。
6. 安全提醒：焊接注意通风与烙铁安全；充电锂电池方案一律否决，v1 只用 USB / 纽扣电池。
7. 文档同步：每阶段更新「进度日志」。
8. 沟通：EDA 里任何报错 / 看不懂的检查项，直接截图发 Agent 询问。

## 五、风险与注意

- 新手焊接短路是头号翻车点：焊接后先目检再用万用表量电源正负极间电阻，再上电。
- CH32V003 烧录需要 WCH-LinkE 调试器（~10 元），预算里要算上；嫌麻烦就用 STC（串口烧录）或 ESP32-C3（USB 烧录）。
