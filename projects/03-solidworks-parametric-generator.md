## 三、技术路线（分阶段）

**技术选型**：Windows + SolidWorks（教育版 / 正版均可）/ Python + pywin32（COM 自动化）/ SolidWorks API 文档 + **宏录制**（录制 VBA 宏再翻译成 Python，是学 API 最好的老师）/ pytest。
> 环境是硬前提：必须有可用的 Windows + SolidWorks。学校机房或个人电脑装教育版均可。

- **阶段 0｜打通 API（2~3 天）**：用 pywin32 连上 SolidWorks（新建零件、画一个矩形、拉伸）——走通"Python 指令 → SW 动作"的最小闭环；学会录制宏并把 VBA 翻译成 Python。产出：`sw_driver.py` 基础驱动。
- **阶段 1｜参数计算与螺栓（4~5 天）**：查手册定螺栓系列尺寸（头高 / 对边距 / 螺距）写纯函数模块 + 手算对照测试 → 调 API 建模（草图 / 拉伸 / 切除）。产出：输入 M8×30 出一个正确螺栓。
- **阶段 2｜齿轮（4~5 天）**：渐开线齿廓用方程离散成样条曲线（分度圆 / 齿顶 / 齿根计算公式），齿根圆 Cutting；先做标准直齿，不做变位。产出：输入 m=2, z=20 出正确齿轮。
- **阶段 3｜工程图与导出（2~3 天）**：API 生成工程图模板（主视图 + 标注）+ 批量导出 STEP / PDF。
- **阶段 4｜包装与收尾（3~4 天）**：统一入口（CLI 或 Flask 表单）、README + 演示 GIF、主页卡片更新。

## 四、Agent 运行规范（精简版，务必遵守）

1. 角色：懂 CAD 二次开发的资深机械工程师兼导师；重点教我"宏录制 → API 翻译"的自学路径和 COM 调用的调试方法。
2. 节奏：一次一个阶段，阶段结束汇报并等我确认；**每个零件建模成功以我屏幕上看到正确模型为准**。
3. 诚实红线：API 调不通就明说并给排查方向，绝不假装"应该能跑"；尺寸计算必须与手册对照，出处写进注释。
4. **实物边界**：SolidWorks 装在 我的 Windows 电脑上，所有 SW 操作由我执行；Agent 负责代码、API 用法解释与报错分析（我截图 / 贴报错给它）。
5. 范围控制：只做标准直齿（不变位、不斜齿）；螺纹用装饰性表述（不改刀路真实螺纹）；不碰装配体高级配合。
6. 代码规范：API 调用封装成驱动模块，业务参数与驱动分离；所有魔法数字注明手册出处；关键逻辑中文注释。
7. 文档同步：每阶段更新「进度日志」。
8. 沟通：API 报错码 / 宏录制看不懂的行，直接贴给 Agent 解读。

## 五、风险与注意

- 最大风险是环境：COM 调用必须本机有 SW 且版本匹配；教育版与专业版 API 一致，放心用。
- 渐开线齿廓不要求精确啮合（那是另一门课），近似即可，README 里说明精度范围。
- pywin32 的常量需要 `win32com.client.gencache.EnsureDispatch` 生成，环境坑让 Agent 给标准解法。
