## 三、技术路线（分阶段）

**技术选型**：SolidWorks（我的课程主力工具）/ 立创 EDA 或 KiCad 的 3D 导出 / 3D 打印（学校实验室或淘宝代打，PLA）。

- **阶段 1｜模型获取（1 天）**：在 EDA 里确认每个元件都挂上了 3D 模型（缺的用立创商城模型补）→ 导出 STEP → SolidWorks 导入检查比例与朝向。产出：干净的 PCB 装配基准件。
- **阶段 2｜外壳设计（2~3 天）**：底座（PCB 定位柱 + 边框）→ 上盖（开孔：USB 口、OLED 窗口、传感器通孔）→ 连接方式（自攻螺丝柱 M2.5 或卡扣）；遵守规范：壁厚 1.6~2mm、间隙 0.2~0.3mm、拔模角、边角圆角。产出：完整装配体 + 干涉检查通过。
- **阶段 3｜打印与装配（1~2 天）**：切片参数（PLA / 0.2mm 层高 / 15~20% 填充 / 无支撑优先摆放）→ 打印 → 去毛刺试装 → 修配（孔位偏差锉刀 / 重打）。产出：装好的实物。
- **阶段 4｜收尾（1 天）**：爆炸图渲染、README 踩坑记录（首次打印偏差多少、怎么修的）、主页更新。

4. **实物边界**：SolidWorks 建模、打印、装配由我完成；Agent 提供设计审查清单、参数建议与问题诊断（把卡尺实测尺寸发给它分析偏差原因）。
5. 范围控制：v1 只做上下盖两件式；不做铰链 / 嵌件 / 多色打印。
6. 文档同步：每阶段更新「进度日志」。
7. 沟通：打印失败或装不上，把失败照片 + 实测尺寸发 Agent 做偏差分析。

## 五、风险与注意

- 经典翻车点是"孔位对不上"：原因通常是 EDA 里元件 3D 模型位置与实际焊接偏移。对策：外壳孔位以**实测焊接后的板子**为准，而不是完全信任 3D 模型。
- 3D 打印孔径会收缩：M2.5 自攻螺丝柱底孔按 2.2mm 起试，宁小勿大（可重打，松了没法救）。
