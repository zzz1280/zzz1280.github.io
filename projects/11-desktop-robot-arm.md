## 三、技术路线（分阶段）

**技术选型**：SG90/MG90S 舵机 × 4（约 8~15 元/个）/ ESP32（复用 08 经验）或 Arduino UNO / PCA9685 16 路驱动（可选，省 IO）/ Python + pyserial + tkinter（上位机）/ PyBullet（仿真）/ SolidWorks + 3D 打印。
> BOM 预算约 100~150 元（舵机为主）。v1 不做逆运动学强制项，先让滑杆控制好玩起来。

- **阶段 0｜方案与仿真（3~4 天）**：定连杆长度（打印件尺寸决定）→ PyBullet 建 4 连杆模型 → 验证可达范围与限位 → 输出结构设计参数表。产出：仿真 demo + 设计输入。
- **阶段 1｜结构设计与打印（4~5 天）**：SolidWorks 设计底座 / 大臂 / 小臂 / 夹指（舵机安装孔位是关键尺寸，对照舵机图纸）；打印并试装（轴承 / 铰接处间隙 0.2~0.4mm）。
- **阶段 2｜固件（3~4 天）**：多路舵机 PWM 控制 → 串口指令协议（如 `#01 P1200\n`）→ 角度软限位 + 上电回中 → 平滑插补（防止抽搐）。
- **阶段 3｜上位机（3~4 天）**：pyserial 通信 → 滑杆面板 → 动作序列录制 / 回放 →（加分）正运动学显示末端坐标。
- **阶段 4｜联调与演示（3~4 天）**：整臂抓取演示（吸管 / 小方块）、调参、拍视频。
- **阶段 5｜收尾（2 天）**：README、运动学小节（连杆参数表 + 公式）、主页卡片更新。

## 四、Agent 运行规范（精简版，务必遵守）

1. 角色：机器人工程师兼导师；重点教我"舵机 PWM → 关节角 → 末端位置"这条链路，以及结构设计里转动副的工程实现（间隙、轴承、强度）。
2. 节奏：一次一个阶段，阶段结束汇报并等我确认；**结构送打印前、固件上电前，都必须先过 Agent 的检查清单**。
3. 诚实红线：演示视频必须真实拍摄；运动学计算结果与仿真 / 实物对得上才能写进 README；卡住就说卡住。
4. **实物边界**：建模、打印、接线、拍摄由我完成；Agent 负责设计审查、代码、调试流程与失败分析（舵机抖动 / 堵转的排查树）。
5. 范围控制：v1 不做逆运动学强制功能、不做闭环反馈（无编码器）、不上 ROS；能稳定抓放就是胜利。
6. **安全红线**：舵机堵转会烧，限位参数上电前必须核对；USB 供电与舵机电源分离（舵机独立 5V 2A），共地。
7. 代码规范：固件指令协议写进 README 文档化；上位机与固件版本配对说明；关键逻辑中文注释。
8. 文档同步：每阶段更新「进度日志」。
9. 沟通：打印件装不上 / 舵机异响 / 控制丢步，拍照 + 描述现象发 Agent，按排查树走。

## 五、风险与注意

- 舵机抖动九成是供电问题（USB 带不动 4 个舵机同时动）：独立 5V 2A 电源 + 大电容，共地。
- 打印件孔位偏差导致卡死：转动副间隙宁大勿小（0.3mm 起），装配前先单件试转。
- 项目跨度大：严格按阶段走，每个阶段都有"能演示的小成果"，避免烂尾。
